# Structural Dynamics & Receptance Analysis (MATLAB)

Structural dynamics, vibration analysis, and frequency response function (FRF / receptance) coursework developed at **UNAQ** (*Análisis Dinámico de Estructuras — ADE*).

## Overview
Contains **MATLAB** scripts for modeling multi-degree-of-freedom (MDOF) dynamic systems, computing receptance matrices, and comparing analytical responses with finite element modal/harmonic simulations.

## Contents
- **MATLAB Scripts (`.m`)** — System definitions and receptance/FRF solvers (`sistema1.m`–`sistema4.m`, `receptancia_sistema1.m`–`receptancia_sistema4.m`, `codigo_1.m`–`codigo_3.m`).
- **`Práctica 1/` & `Práctca 2/`** — Lab practices, exported data, and final reports.
- **`Tarea 10/`** — CAD geometry (`.sldprt`, `.step`) and ANSYS Workbench dynamic analysis (`.wbpj`).
- **Supporting Reports & Data** — Excel datasets and `.pdf` / `.docx` technical reports.

## Tools & Technologies
- **MATLAB** (Dynamic system modeling, FRF & receptance calculation)
- **ANSYS Workbench** (Modal & harmonic response verification)

> *Note: Large ANSYS result files (`.rst`, `.db`) are excluded via `.gitignore`.*
